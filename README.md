# Skillboss

Практическая база собственных навыков для Codex. Каждый навык обязан давать исполнимый процесс: когда применять, какие входные данные нужны, как проверить результат и когда остановиться.

## Принцип сборки

Исходный репозиторий сначала классифицируется.

| Тип источника | Действие |
| --- | --- |
| Самостоятельный навык или повторяемый метод | Собрать независимый навык с проверяемым результатом. |
| Целостная система: рантайм, набор модулей, команды, агенты, тесты и инсталлятор | Не дробить. Хранить карточку источника и использовать систему в исходном виде. |
| Материал с частично независимыми практиками | Выделять только части с собственным входом, выходом и проверкой; фиксировать причину разделения. |

Исходники и лицензионные границы находятся в [`sources/`](sources/). Навыки лежат в [`skills/`](skills/). Внешний код не копируется без отдельной проверки лицензии и необходимости.
